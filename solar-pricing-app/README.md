# برنامج تسعير منظومات الطاقة الشمسية — بلاد اوتو

تطبيق سطح مكتب Windows يعمل أوفلاين بالكامل لتسعير منظومات الطاقة الشمسية وإصدار عروض أسعار PDF احترافية بالعربي RTL.

## الفكرة

تُدخل مخزون المواد مرة واحدة، وبعدها لكل زبون تعطي البرنامج 3 أرقام فقط:
**مساحة السطح (م²) + الأمبير المطلوب نهاراً + الأمبير المطلوب ليلاً**
فيحسب المنظومة الكاملة من المخزون (ألواح، بطاريات، انفيرتر، مواد ثانوية، أجور عمل) بثلاثة مستويات (اقتصادي / متوسط / ممتاز) ويصدّر عرض سعر PDF بصفحة A4 واحدة.

## التقنيات

- **Electron + React (Vite)** — واجهة سطح المكتب، عربي RTL بخط Cairo مضمّن محلياً
- **better-sqlite3** — قاعدة بيانات SQLite محلية (في مجلد بيانات المستخدم)
- **webContents.printToPDF** — تصدير الفاتورة من قالب HTML/CSS عربي
- **electron-builder (NSIS)** — ملف تنصيب Windows

## هيكل المشروع

```
electron/
  main.js            عملية Electron الرئيسية + IPC handlers
  preload.js         جسر آمن بين الواجهة والعملية الرئيسية
  db/                schema.js + seed.js + فتح قاعدة البيانات
  lib/
    calc.js          محرك الحساب (وحدة منطقية بحتة قابلة للاختبار)
    quoteService.js  بناء العروض من المخزون + الحفظ
    invoiceTemplate.js  قالب فاتورة HTML عربي RTL
    fonts.js         تضمين خط Cairo كـ base64 داخل الـ PDF
src/                 واجهة React (مخزون، إنشاء عرض، عروض محفوظة، إعدادات)
tests/               اختبارات vitest لمحرك الحساب وبناء العروض
scripts/build-win.sh بناء ملف تنصيب Windows من بيئة Linux
```

## أوامر التطوير

```bash
npm install          # التنصيب (يعيد بناء better-sqlite3 لـ Electron تلقائياً)
npm run dev          # تشغيل تطويري (vite + electron)
npm test             # اختبارات محرك الحساب (18 اختبار)
npm run build:win    # بناء ملف تنصيب Windows (على Windows مباشرة)
bash scripts/build-win.sh  # بناء ملف تنصيب Windows من Linux (cross-build)
```

## المعادلات

كل الثوابت قابلة للتعديل من شاشة الإعدادات (فولتية النظام، ساعات الشمس، الكفاءة، معامل أمان الانفيرتر، عمق تفريغ البطارية، ساعات التغطية الليلية، مساحة اللوح).

المثال المرجعي المستخدم بالاختبارات: منظومة 15 أمبير نهاراً وليلاً بسطح 28م² تعطي 10 ألواح 650 واط + بطاريتين 16kWh + انفيرتر 6kW بمجموع 9,686,000 دينار — مطابق للفاتورة المرجعية الفعلية.

## ملاحظات البناء العابر (Linux → Windows)

- بيئة البناء تحتاج: `wine64` و `wine32:i386` (لخطوة rcedit) و `Xvfb`
- تحميل ثنائيات Electron و NSIS يتم من مرآة npmmirror (مضبوطة في `.npmrc` وسكربت البناء)
- ثنائية better-sqlite3 الخاصة بويندوز تُنزّل جاهزة من مرآة npmmirror وتُستبدل مؤقتاً وقت التحزيم فقط
