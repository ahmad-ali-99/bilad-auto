# ⚡ بلاد أوتو — العرض الهندسي (تطبيق سطح المكتب)

تطبيق مستقل يشتغل داخل الحاسوب فقط (أوفلاين بالكامل): تدخل أرقام عرض السعر
(ألواح / بطاريات / انفرترات / ساعات الليل / أمبير النهار) ويشغّل العرض الهندسي
ثلاثي الأبعاد بالجودة القصوى مع الجولة التعريفية — مصمّم للربط بشاشة عرض بالمكتب.

> هذا التطبيق منفصل تماماً عن تطبيق العروض (bilad-auto) — تطبيق العروض يبقى للعروض فقط.

## التشغيل أول مرة (ويندوز)

1. نصّب [Node.js LTS](https://nodejs.org) (ضغطتين، كلشي افتراضي).
2. نزّل هذا الريبو: زر **Code → Download ZIP** من صفحة GitHub، وفك الضغط بأي مجلد.
3. افتح مجلد المشروع ودبل كليك على **`start.bat`** — أول مرة راح ينصّب ويبني (دقايق)،
   وبعدها يفتح العرض مباشرة بالشاشة الكاملة.

من المرة الثانية `start.bat` يفتح فوراً بلا تنصيب.

## وضع الشاشة (كيوسك)

- يفتح **بشاشة كاملة** تلقائياً، وإذا أكو **شاشة خارجية** موصولة يفتح عليها بشكل تلقائي.
- **F11** يبدّل الشاشة الكاملة، و**Esc** يطلع منها.
- للتشغيل بنافذة عادية: `npm start -- --window`

## الأوامر (لمن يحب الطرفية)

```bash
npm install      # مرة وحدة
npm run build    # بناء الواجهة
npm start        # تشغيل التطبيق
npm run dist     # تغليف ملف exe محمول (مجلد release/)
```

## الأصول الثقيلة (موديل المدينة لاحقاً)

ملف الريبو الواحد على GitHub محدود بـ100MB، فموديل City pack 7 والأصول الضخمة
(حتى 3–7GB) ما تدخل بالريبو — تُرفع على **GitHub Releases** (سقف 2GB للملف، مع تقسيم تلقائي):

- `node scripts/pack-assets.mjs city` — يضغط `public/city` لملفات جاهزة للرفع.
- `node scripts/fetch-assets.mjs` — ينزّل ملفات آخر Release (يحتاج `GITHUB_TOKEN` لأن الريبو خاص)،
  وبعدها تفك ملفات zip داخل `public/` وتعيد `npm run build`.

أصول العرض الحالية (`public/showcase` — خامات وسماء، ~177MB) موجودة بالريبو نفسه فلا تحتاج شي.
